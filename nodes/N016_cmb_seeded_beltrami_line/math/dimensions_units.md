# Dimensional checks

- u_nu: J m^-3 Hz^-1; integrating dnu gives u: J m^-3.
- n_gamma: m^-3; temperature supplies k_B T (J) and h_P c/(k_B T) (m).
- F=E+icB: V/m; epsilon0 integral abs(F)^2/2 has units J.
- curl F=k F: both sides V/m^2; E=e cos(ckt), B=-e sin(ckt)/c are dimensionally consistent.
- H_B=integral A dot B dV: T^2 m^4; lambda H_B/(2mu0): J.
- tau L and C Theta^2/(2L): J; using a twist density in place of Theta changes dimensions and length scaling.
- Delta m^2 c^3 D/(2E hbar): dimensionless for SI masses; if masses are rest energies, use Delta(epsilon^2) D/(2E hbar c).

Normalized numerical Maxwell examples set c=epsilon0=mu0=1 explicitly; Planck densities and calibrated cross-sections use SI.
